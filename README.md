# HOW TO RUN THE APP
1. Download Expo Go app on your phone (can be on iOS or Android)
2. Clone this repo and install all packages through terminal (npm install)
3. Run the app by entering "npm start" on terminal
4. Press 's' on terminal to switch to Expo Go instead of development build
5. Scan the qr code using your phone
6. Open our app using Expo Go

# ABOUT OUR APP
- Frontend layer: React native
- Backend layer: Supabase (covers both database and authentication)
- Development build: Expo Go (supports both iOS and Android app)
